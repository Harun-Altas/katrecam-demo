# Katre Cam — Tasarım Demosu

3 sayfalı HTML/CSS/JS ön izleme: `index.html`, `urunlerimiz.html`, `urun-detay.html`.

**DİKKAT:** Bu site eksik kataloglu bir tasarım demosudur. 19 kategori kartı bulunmaktadır, yalnızca cam balkon için ürün detay sayfası hazırlanmıştır. 70 ürünün tam sayfaları henüz tamamlanmadı.

`assets/` klasörüne `logo.jpg`, `hero.jpg`, `hero.mp4`, `card0.jpg`–`card6.jpg` eklenmelidir; kaynağı kullanıcı tarafından onaylanmış site paketidir. Yüklenene kadar bazı fotoğraflar ve logo görünmez.

Vercel: framework `Other`, kök dizin `/`, build komutu yok. `robots.txt` ve `vercel.json` arama motoru dizinlemesini engeller. Katrecam.com DNS'i değiştirilmemelidir.

Görsel referansları temsilîdir, gerçek Katre Cam projeleri olarak sunulmamalıdır. Vercel Hobby planının ticari kullanım kısıtlamasına dikkat edilmelidir.
